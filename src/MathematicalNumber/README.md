## 📌 About This Repository

This repository contains Java programming problems focused on mathematical logic, number theory, and problem-solving techniques.

The main objective is to strengthen mathematical thinking, improve logical reasoning, understand number properties, and develop problem-solving skills for technical interviews.

**Primary Focus:**
- Mathematical logic and number theory
- Prime number algorithms
- GCD and LCM calculations
- Special number identification
- Efficient mathematical operations
- Java loops, conditions, and methods
