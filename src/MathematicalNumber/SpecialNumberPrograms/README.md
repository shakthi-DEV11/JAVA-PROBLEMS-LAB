## 📚 Problem List

### 01\. Perfect Number

**Definition:** A number is called a Perfect Number if the sum of its proper divisors (excluding itself) is equal to the original number.

**Example:**

``` text
Input: 28
Divisors: 1, 2, 4, 7, 14
Sum: 1 + 2 + 4 + 7 + 14 = 28

Output: Perfect Number
```

### 02\. Strong Number

**Definition:** A number is called a Strong Number if the sum of the factorials of its digits equals the original number.

**Example:**

``` text
Input: 145

1! = 1
4! = 24
5! = 120

Sum = 1 + 24 + 120 = 145

Output: Strong Number
```

### 03\. Armstrong Number

**Definition:** A number is called an Armstrong Number if the sum of each digit raised to the power of the total number of digits equals the original number.

**Example:**

``` text
Input: 153

1³ = 1
5³ = 125
3³ = 27

Sum = 1 + 125 + 27 = 153

Output: Armstrong Number
```

### 04\. Automorphic Number

**Definition:** A number is called an Automorphic Number if its square ends with the same digits as the original number.

**Example:**

``` text
Input: 25

25 × 25 = 625

Last two digits = 25

Output: Automorphic Number
```

### 05\. Neon Number

**Definition:** A number is called a Neon Number if the sum of the digits of its square equals the original number.

**Example:**

``` text
Input: 9

9 × 9 = 81

Sum = 8 + 1 = 9

Output: Neon Number
```

### 06\. Harshad Number

**Definition:** A number is called a Harshad Number if it is divisible by the sum of its digits.

**Example:**

``` text
Input: 18

Sum = 1 + 8 = 9

18 % 9 = 0

Output: Harshad Number
```

### 07\. Spy Number

**Definition:** A number is called a Spy Number if the sum of its digits equals the product of its digits.

**Example:**

``` text
Input: 1124

Sum = 1 + 1 + 2 + 4 = 8

Product = 1 × 1 × 2 × 4 = 8

Output: Spy Number
```

### 08\. Duck Number

**Definition:** A number is called a Duck Number if it contains at least one zero, excluding leading zeros.

**Example:**

``` text
Input: 1023

Digits: 1, 0, 2, 3

Contains zero: Yes

Output: Duck Number
```

### 09\. Disarium Number

**Definition:** A number is called a Disarium Number if the sum of its digits raised to their respective positions equals the original number.

**Example:**

``` text
Input: 135

1¹ = 1
3² = 9
5³ = 125

Sum = 1 + 9 + 125 = 135

Output: Disarium Number
```

### 10\. Abundant Number

**Definition:** A number is called an Abundant Number if the sum of its proper divisors is greater than the original number.

**Example:**

``` text
Input: 12

Proper Divisors: 1, 2, 3, 4, 6

Sum = 1 + 2 + 3 + 4 + 6 = 16

16 > 12

Output: Abundant Number
```
