# 🔢 Prime Numbers — Java

A collection of Java programs focused on **Prime Number operations**, mathematical logic, and number-based problem solving.

## 📂 Project Structure

```text
PrimeNumbers/
│
├── CheckPrimeNumber.java
├── PrimeRange.java
├── CountPrimeNumbers.java
├── SumofPrimeNumbers.java
└── NthPrimeNumber.java
```

## 📚 Programs & Concepts

| Program | Description |
|---|---|
| CheckPrimeNumber | Checks whether a number is prime or not. |
| PrimeRange | Prints prime numbers within a given range. |
| CountPrimeNumbers | Counts the number of primes in a range. |
| SumofPrimeNumbers | Calculates the sum of prime numbers in a range. |
| NthPrimeNumber | Finds the Nth prime number. |

