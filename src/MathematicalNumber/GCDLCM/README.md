## 📐 Mathematical Formulas

**GCD (Euclidean Algorithm)**

```text
GCD(a, b) = GCD(b, a % b)
```

**LCM Formula**

```text
LCM(a, b) = (a × b) / GCD(a, b)
```

**Co-Prime Numbers**

Two numbers are co-prime if their GCD is 1.

Example:

```text
Numbers: 8 and 15

GCD = 1

Result: Co-Prime
```
