# Java Number Problems

## Package: `basicnumbers`

### Level 1 — Basic

Practice the following Java number programming problems.

| No. | Problem |
|---:|---|
| 1 | Positive, Negative or Zero |
| 2 | Even or Odd |
| 3 | Largest of Two Numbers |
| 4 | Largest of Three Numbers |
| 5 | Swap Two Numbers |
| 6 | Reverse a Number |
| 7 | Square and Cube |
| 8 | Divisible by 5 and 11 |
| 9 | Find Last Digit |
| 10 | Count Digits |

---

## Instructions

1. Use Java programming language.
2. Use `Scanner` for user input.
3. Practice `if-else` conditions.
4. Practice `for` and `while` loops wherever required.
5. Use arithmetic operators.
6. Avoid unnecessary built-in methods.
7. Test your programs with different inputs and edge cases.

## Goal

Complete all 10 problems independently and understand the logic behind each solution.

**Note:** This repository contains problem statements only. Solutions must be implemented independently.
