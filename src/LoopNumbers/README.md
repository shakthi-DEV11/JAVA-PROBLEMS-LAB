### Level 2 — Loop Based

Practice the following Java number programming problems using loops.

| No. | Problem |
|---:|---|
| 1 | Reverse a Number |
| 2 | Sum of Digits |
| 3 | Product of Digits |
| 4 | Palindrome Number |
| 5 | Armstrong Number |
| 6 | Factorial of a Number |
| 7 | Multiplication Table |
| 8 | Power of a Number Without Math.pow() |
| 9 | Count Even and Odd Digits |
| 10 | Find the Largest Digit |

---

## Instructions

1. Use Java programming language.
2. Use `Scanner` for user input.
3. Practice `while` and `for` loops.
4. Use arithmetic operators (`+`, `-`, `*`, `/`, `%`).
5. Understand digit extraction using `% 10`.
6. Remove the last digit using `/ 10`.
7. Avoid unnecessary built-in methods.
8. Handle edge cases such as `0`, `1`, and negative numbers.

## Goal

Complete all 10 problems independently and understand loop-based number manipulation.

**Note:** This repository contains problem statements only. Solutions must be implemented independently.
